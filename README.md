# LGA FrameRev — Releases

Este repositorio no contiene el codigo fuente: existe para publicar los artefactos de
**LGA FrameRev** y permitir que se descarguen sin credenciales. El codigo vive en
`legandrop/LGA_FrameRev`, que es privado.

## Descargas

Ir a **[Releases](../../releases/latest)** y elegir el artefacto de la plataforma:

| Archivo | Uso |
|---|---|
| `LGA_FrameRev_Setup_v<version>.exe` | Instalacion o actualizacion en Windows |
| `LGA_FrameRev_Mac_v<version>.dmg` | Primera instalacion en macOS |
| `LGA_FrameRev_Mac_v<version>.zip` | Actualizacion in-place en macOS |

Los tres artefactos de una version comparten la misma release. Windows y macOS pueden
publicarse en momentos distintos: cada publicador reemplaza solamente sus propios archivos.

## LGA Updates

Este repo forma parte del manifiesto publico de `legandrop/LGA_Updates`. FrameRev todavia no
esta incorporado al catalogo visual de PipeSync; esa integracion se hara en una etapa separada.
